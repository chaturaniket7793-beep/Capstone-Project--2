Capstone Project 2
--------------------------------------------------------------------------------------------
Docker, AWS and Real-World DevOps Deployment

This capstone project is designed to move you from sandbox learning into real-world
DevOps execution. Here, you will apply Docker and Docker Compose concepts on
actual cloud infrastructure.
The intent is to expose you to real operational concerns such as networking, security,
deployment, and observability — exactly what DevOps engineers handle in practice.

Capstone Intent
-----------------------------------------------------------------------------------------------
Unlike earlier assignments, this project simulates a real DevOps scenario. You will
containerize an application, deploy it on AWS, and ensure it is reachable, observable,
and manageable. This project connects Docker with cloud infrastructure.

Project Objective
----------------------------------------------------------------------------------------------
• Containerize a full-stack application (frontend, backend, database)
• Write Dockerfiles for each component
• Use Docker Compose for service definitions and networking
• Deploy the application on AWS EC2
• Configure security groups and networking
• Add health checks and logging

Detailed Step-by-Step Approach
----------------------------------------------------------------------------------------------
• Prepare application source code for containerization
• Create Dockerfiles for frontend, backend, and database services
• Define services, networks, and volumes in docker-compose.yml
• Provision an AWS EC2 instance and install Docker
• Deploy the application using Docker Compose on EC2
• Verify application access using public IP or domain
• Validate health checks and logs

Real-World Expectations
-----------------------------------------------------------------------------------------------
• Your application should survive container restarts
• Logs should help in debugging issues
• Screenshots of running application on AWS
